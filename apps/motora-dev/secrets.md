# motora-dev Secrets

## Required Secrets

This application requires the following secrets to be configured in GCP Secret Manager:

| Secret Name | Description |
|-------------|-------------|
| `motora-dev-database-url` | Database connection URL |
| `motora-dev-supabase-url` | Supabase project URL |
| `motora-dev-supabase-service-role-key` | Supabase service role key |
| `motora-dev-cors-origins` | Allowed CORS origins |
| `motora-dev-domain` | Application domain |
| `motora-dev-cookie-domain` | Cookie domain setting |
| `motora-dev-basic-auth-user` | Basic authentication username |
| `motora-dev-basic-auth-password` | Basic authentication password |
| `motora-dev-allowed-emails` | Allowed email addresses |
| `motora-dev-isr-secret` | ISR (Incremental Static Regeneration) secret |
